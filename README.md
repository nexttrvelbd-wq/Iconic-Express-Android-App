# Iconic Express Premium Android App

A premium Android WebView app for https://iconicexpressbd.com/

## Included
- Iconic Express supplied logo used for splash screen and launcher icon
- Premium Purple + Sky Blue top bar
- Splash screen
- Home / Menu / Call / Booking bottom navigation
- Online booking opens the Iconic Express website inside the app
- Call button dials 01715-668016
- JavaScript, DOM storage and cookies enabled for booking flows
- Back button navigates WebView history
- Tel/mail/sms/WhatsApp links can open native Android apps

## Build APK
1. Open this folder in Android Studio.
2. Allow Gradle sync and install Android SDK 35 if prompted.
3. Build > Generate App Bundles or APKs > Generate APKs.
4. For a Play Store build, use Build > Generate Signed App Bundle / APK.

Package: com.iconicexpress.app
Version: 2.0.0
